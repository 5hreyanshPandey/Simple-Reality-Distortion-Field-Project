# Simple-Reality-Distortion-Field-Project

A real-time visual manipulation system that applies surreal distortions to live video feeds, inspired by the concept of a “Reality Distortion Field.” This project explores creative glitch effects, spatial warping, and temporal distortions to transform reality into an immersive digital experience.

##  Features

* Spatial and temporal distortions
* Glitch-based visual effects
* GPU-accelerated rendering
* Interactive controls for real-time manipulation

## Tech Stack

* Python
* OpenCV
* GPU Acceleration


##  Objective

To experiment with advanced visual transformations and create an immersive, surreal video environment while keeping the implementation simple and efficient.


##  Output

Real-time distorted video effects that redefine normal perception with artistic and experimental visuals.
